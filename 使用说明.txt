守译  ——  使用说明
========================================

这是什么
----------------------------------------
看屏幕：框选或选中一个窗口，程序自动识别上面的文字，翻译成中文，
        直接盖在原文的位置上。

翻文件：Word（.docx）和 Excel（.xlsx）整份翻过来，
        排版不变，只有字变成中文。

翻图片：合同照片、微信截图、扫描件，认出字来直接翻，
        不用先打字。


第一步：先让桌面上有个图标（只用做一次）
----------------------------------------
双击    安装桌面快捷方式.bat

桌面上就会出现「守译」图标。以后双击那个图标就能启动。


第二步：启动
----------------------------------------
双击桌面上的「守译」图标。

或者直接双击文件夹里的    启动.bat

（启动后不会弹黑窗口，直接出界面，这是正常的。）

如果双击了没反应，改双击   启动-调试.bat
它会把错误信息留在窗口里，截图发给我就能看出问题。


第三步之一：翻屏幕上的东西
----------------------------------------
推荐做法：选窗口（这样窗口拖到哪，译文就跟到哪）

1. 点「选择窗口」，在列表里选中要翻译的窗口
   （比如微信、浏览器、游戏窗口）

2. 如果只想翻窗口里的一小块（比如聊天记录区），
   再点「在窗口内框选」，在窗口里拖一个框

3. 点「▶ 开始翻译」

译文会盖在原文上。窗口随便拖、随便改大小，译文都会跟着走。

另一种做法：框选屏幕区域（位置固定，不跟随）
点「框选屏幕区域」，在屏幕上拖一个框。适合翻译固定不动的画面，
比如全屏视频的字幕。窗口一挪，框就对不上了 —— 所以一般用「选窗口」。

想看原文，在「字幕显示」页勾上「同时显示原文」。
停止翻译：点「■ 停止」。想重选：再点一次对应的按钮。


第三步之二：翻一整份文件（Word / Excel）
----------------------------------------
到「文本翻译」页，点最右边的    翻译文档…    按钮。

1. 选一个 .docx（Word）或 .xlsx（Excel）文件
2. 选译文存到哪
3. 等几秒到几十秒

出来是一个新文件。合同、报价单、邮件存档都能这么翻。

保留什么、不保留什么：

    保留      段落样式、表格、编号、列宽、合并单元格、
              字体颜色、加粗标题、数字格式、公式
    不保留    段落里某个词单独加粗
              （整段的格式在，逐字的格式会没）

数字和公式不会被翻译，也不会被当成文字弄坏。

Excel 里重复出现的词只翻一次，所以又快，同一份文件里译法也一致。

目前支持 .docx 和 .xlsx 两种。纯文本、.csv、.srt 请用旁边的「导入文件」。


第三步之三：翻一张图片（合同照片 / 微信截图 / 扫描件）
----------------------------------------
客户发来的常常不是文件，是一张照片。到「文本翻译」页，点
    翻译图片…    按钮。

1. 选一张 .jpg / .png / .bmp / .webp / .tif
2. 等几秒到几十秒
3. 上面的框里是原文，下面的框里是译文

不用先另存、不用手动打字。「复制译文」「保存译文」照常能用。

图片识别和屏幕翻译用的是同一个引擎，所以：

    俄文要认得，得先在「设置 → 识别与高级」里装过俄文识别模型
    数字会被保护，丢了会红字提醒
    你自己的词库照常生效（城市名、术语按你的词库翻）

手机拍照的建议：

    光线均匀、别反光、别抖、正着拍
    整页都在画面里，字别太小
    太大的照片程序会自动缩小再识别

翻不出来的情况：

    模糊、斜着拍、手写字 —— 这三类离线识别不了。
    换张清楚点的，或者把字打出来用「翻译」按钮。


第三步之四：翻 PDF（合同、报价单、扫描件）
----------------------------------------
合同基本都是 PDF。到「文本翻译」页，点    翻译 PDF…    按钮。

1. 选一个 .pdf
2. 等一会（每页几秒到十几秒）
3. 上面的框里是原文，下面的框里是译文，每页用小标题隔开

软件会**一页一页判断**该怎么读：

    有文字层的页（对方用软件导出的）  直接读，又快又准
    扫描的页（打印签字后拍的照片）    自动识别，跟屏幕翻译用同一个引擎

所以「第 1 页是电子版、第 2 页是扫描件」这种混着的合同也能翻。
扫描页要多花一些时间。

数字（金额、数量、日期）会被保护，扫描页上的数字也一样。

翻完点「复制译文」或「保存译文」拿走。

翻不了的情况：

    有密码的 PDF       先解开；软件会提示「这个 PDF 有密码」
    纯图片而且拍得糊   识别不出来，会提示「没认出字」
    表格类 PDF         文字能翻，但表格线不会画出来——
                       想要带表格的，用「翻译文档…」翻 .xlsx


快捷键（在任何程序里都有效）
----------------------------------------
    F8    框选屏幕区域
    F9    开始翻译
    F10   停止
    F11   暂停 / 继续

不想翻了用哪个？
    「暂停」  —— 停一下，模型留在内存里，点「继续」是秒开的
    「停止」  —— 彻底结束，释放内存；下次开始要重新加载模型（约 8 秒）

停止不是瞬间生效的：如果正在识别或翻译一句话，会等这一句做完再停，
状态栏会显示「正在停止…」。这期间「开始」是灰的，避免同时跑两个。


三种语言，两个方向都行
----------------------------------------
    中文 ↔ 英语
    中文 ↔ 俄语
    英语 ↔ 俄语

屏幕翻译时，俄语和中文互译会自动经英语中转（没有现成的俄中模型），
所以俄中和英中比会慢一点，这是正常的。翻文件没这个问题。


关于联网和隐私（重要，先看这段）
----------------------------------------
软件里有两类翻译引擎，在「引擎与词库」页的下拉框里选：

    离线（默认）              文字全部在本机处理，一个字都不发到网上。
                              质量一般，慢（大约 2 秒一句）。

    联网 · MyMemory（免费）   不用申请、不用花钱，中文俄语都通。
                              质量比离线好很多。每天有额度上限，
                              文字会发到第三方服务器。

    联网 · 有道（免费，快）   只稳中英，俄语别用这个。

    联网 · 百度翻译（需密钥） 最稳、额度最大（标准版每月免费 5 万字符）。
                              到 fanyi-api.baidu.com 申请 appid 和密钥，
                              填在同一页下面。文字会发到百度。

    联网 · 自定义大模型       接你自己的模型：DeepSeek、Moonshot、通义、
    （OpenAI 兼容）           本地的 Ollama / LM Studio，都行。
                              质量最好，按字收费。填法见下一节。

看合同、报价、客户聊天这类不方便外发的内容，用「离线」。
只想要翻得准，就换成「联网 · MyMemory」试试，反正不花钱。
要最好的质量，就接一个大模型。

换引擎对全部功能都生效：屏幕翻译、Word、Excel、图片都跟着变。


接你自己的大模型（DeepSeek / Ollama / 公司内部网关）
----------------------------------------
「引擎与词库」页选中「联网 · 自定义大模型」，下面会出现五行：

    接口地址    填到 /v1 为止
    模型名      接口要求的那个名字
    API Key     本地模型留空
    提示词      留空用默认那句；可以写 {src} {tgt} 当占位符
    超时(秒)    默认 60

几个常见的填法：

    DeepSeek        https://api.deepseek.com/v1     deepseek-chat
    Moonshot        https://api.moonshot.cn/v1      moonshot-v1-8k
    本地 Ollama     http://localhost:11434/v1       qwen2.5:7b
    本地 LM Studio  http://localhost:1234/v1        界面上显示的那个名字
    公司网关        https://网关地址/v1             网关里的模型名

只填域名也行，例如 https://api.deepseek.com，程序会自动补上 /v1。

填完点「测试连接」。它会真的发一个词过去：

    ✓ 通了。…… 回的是「……」      地址、密钥、模型名全对
    ✗ HTTP 401 密钥不对……        换 API Key
    ✗ HTTP 404 接口地址不对……    多半是少了 /v1
    ✗ 网络错误：……               本机连不上那个地址

测试发的是「莫斯科」一个词，花不了几分钱。

用这个引擎时，脱敏和数字保护照常生效：公司名和金额在发出去之前
就已经换成占位符了。


用联网引擎时，敏感信息会自动遮住
----------------------------------------
选中任何一个联网引擎后，「引擎与词库」页会多出一个勾选框，默认是开着的：

    发送前遮住敏感信息（公司名、税号、银行账号、电话、邮箱、网址）

它的作用是：发出去的文字里，这些东西先被换成 [[C1]]、[[P1]] 这样的占位符，
翻完再换回来。所以

    你在译文里看到的，还是原来的公司名和原来的号码；
    而翻译服务器上，只看到 [[C1]]。

价格、日期、数量、金额不遮——遮了译文就没用了。

万一翻译服务把占位符弄丢了，程序会在下面用红字提醒
「有 N 处敏感信息没能还原」，并写进日志。看到这句请核对译文。

用离线引擎时没有这个勾选框，也没有必要有——离线引擎一个字都不外发。


数字会被保护起来
----------------------------------------
报价单里最要紧的就是数字，而机器翻译最容易毁的就是数字。

离线引擎走的是「俄语→英语→中文」两跳（没有现成的俄中模型），
英语那一跳会把长数字搞坏。实测过的例子：

    600 000 рублей   →  "600,0"        少了三个零
    от 1000 штук     →  "1,0"          变成小数
    по 20 штук       →  "20 grand"     20 变两千
    Минимальная партия 500 штук  →  整句"最小批量"没了

试过改数字写法，没用——喂 600000 进去照样出 600,0。
所以程序改成：**翻译前先把数字取出来，翻完再放回去**。
模型根本没机会碰到数字。

万一哪个数字真的没能放回去，程序会在下面用红字提醒
「有 N 个数字没能还原」，并写进日志。

**这条不是小事：数字丢了，句子照样通顺，读的人看不出来。**
看到红字提示，请对着原文核一遍。


软件里的东西都不是我们写的
----------------------------------------
设置窗口最后一页是「关于」，里面列了所有第三方组件和它们的授权。

其中要注意的是：内置的中俄词典来自 FreeDict，是 CC BY-SA 3.0，
**可以商用，但要求署名**。那一页上的内容就是署名，请留着，别删。

（「关于」页有个「复制全部」按钮，别人问起授权，点一下就能整段发给对方。）


想让某些词固定翻译
----------------------------------------
软件自带 196 条中俄外贸词，两个方向都管
（报价、付款、交货、运输、单证、包装、索赔……）。

俄译中 91 条，中译俄 105 条。中译俄那部分管的不只是术语，还有称呼和客套——
比如「您」不会给你翻成对朋友说的 Ты，「顺祝商祺」也不会翻成「祝你好运」。

在「引擎与词库」页能看到全部，最上面有「筛选」框，
打几个字就只留下相关规则。

想加自己的词，在同一页填：

    原文：АКБ              译文：蓄电池
    原文：我的产品型号       译文：Мой товар

三个要知道的：

  · 你自己加的排在内置的后面。原文一样时，你的覆盖内置的。

  · 表格里有一列「生效条件」，意思是「只在原文出现这个词时才动手」。
    比如看到「顺序 → 订单，生效条件 заказ」，那不是说它见到"顺序"就改，
    而是只在原文真出现 заказ 时才改。这是防止它改坏别的句子。

  · 内置规则删不掉，但你可以加一条原文一样的覆盖它。

换引擎不用重做词库：内置的每条规则都同时收录了各个引擎的错法。


整表导入 / 导出
----------------------------------------
词多了以后一条条敲太慢。同一页有「导入词表」和「导出词表」两个按钮。

「导入词表」直接认客户发来的 Excel 表格，不用先转格式：

    .xlsx / .xlsm    Excel 工作簿（推荐，编码不会出错）
    .csv             逗号分隔（中文表格的 GBK 编码也认）
    .tsv / .txt      制表符分隔

格式要求就两条：

    第一列是原文，第二列是译文；
    第一行如果是表头（写着「原文 / 译文」「Термин / Перевод」之类），
    会自动跳过，不会当成一条术语。

「导出词表」导出的 .tsv 可以丢进 Excel 编辑，改完再导回来，
规则的模式、作用侧、开关状态都会原样保留。

（导入完如果哪一行读不懂，程序会弹窗告诉你是哪一行，不会默默少几条。）


常见问题
----------------------------------------
问：双击没反应？
答：双击  启动-调试.bat  看报错。多半是文件夹没解压完整。

问：识别不出文字？
答：把框选范围收小，只框住文字本身，避开半透明背景。
    也可以在「高级」页调低「识别置信度下限」。

问：翻译得太慢？
答：换成「联网 · MyMemory」，比离线快也比离线准。
    或者到「高级」页把「识别分辨率上限」调低、刷新间隔调大。

问：翻一整天文件，联网额度够吗？
答：MyMemory 的匿名额度不大，几十页的合同可能翻到一半就提示用完。
    长文档建议用百度（每月免费 5 万字符）或离线引擎。

问：提示"该引擎不支持这个语言对"？
答：「联网 · 有道」只支持英中互译。俄语请用离线或 MyMemory。

问：翻出来的文件打不开 / Word 说内容有问题？
答：先把翻之前的原文件发我。程序只改文字、不动其它部分，
    如果真出现这种情况，多半是原文件本身有特殊结构。


哪些文件不能删
----------------------------------------
    runtime\     程序自带的运行环境，删了就启动不了
    models\      离线翻译模型（约 680 MB），删了离线翻译就不能用
    app\         程序本体

整个文件夹可以随便复制、搬去别的电脑、放 U 盘里，
不需要在那台电脑上安装任何东西。
